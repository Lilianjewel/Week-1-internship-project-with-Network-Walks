# Week-1-internship-project-with-Network-Walks
The week one internship project in Cyber security is all about downloading VirtualBox and Kali linx, installing them and running linux through the VirtualBox machine. It is advisable to run Kali through VirtualBox to avoid the system crashing and also prevent the system from being attacked by hackers. We were also asked to assign the networks to kali and the IP address to the machine to each of them.
